# DSH 工作流库

**把成功完成的任务保存为工作流，下次换个参数继续用。**

## 核心功能

- **工作区对话提炼**：搜索并读取当前工作区的对话，可整段提炼，也可勾选多条消息或编辑文本片段后提炼。
- **材料预览**：提交前检查实际选中的材料，长对话支持分页和跨页选择。
- **工作流管理**：支持搜索、新建、编辑、预览和本地保存。
- **参数化复用**：填写本次参数，预览后交给 DSH 智能体按模板执行。
- **导入导出**：通过 JSON 备份、迁移和分享工作流。

## 快速使用

在 DSH 插件管理器中安装 `dsh-diy-workflow`，启用后刷新页面，打开侧栏的「工作流库」。

**保存流程：** 打开当前工作区的普通目标会话 → 选择对话 / 内容提炼 → 读取来源对话 → 整段或部分内容 → 预览材料 → 确认提炼生成 → 等待完成 → 读取提炼结果 → 审阅并保存。

部分提炼支持勾选消息，并编辑选中消息以保留需要的文本片段。请求提交到当前空闲目标会话，保存时记录来源对话 ID。

### v0.2.0 边界说明

- 来源限定当前工作区的未归档普通对话，不读取子智能体；通过宿主打开历史可能激活会话，但不会自动发送模型请求。
- 整段指可见用户/助手文本，不包含内部推理、工具原始输出、附件内容或中断回复。加载不完整时报错；材料超过 120000 字符时要求缩小范围，不静默截断。
- 局部提炼只提交所选材料，但不会清除目标会话原有上下文。需要隔离时，先打开同一工作区的空白会话作为生成目标。
- 读取结果是快照，新增消息需重新读取。生成结果必须人工审阅。

**再次使用：** 选择工作流 → 填写参数 → 预览 → 确认运行到当前空闲会话。

> 工作流由智能体按模板执行，并非历史工具调用的精确重放。提炼和运行会消耗模型额度，仍遵守当前权限要求；保存或分享前请检查敏感信息。

适配 DSH `0.2.2-rc.1`，仅支持本机 GUI。若已安装旧包 `dsh-workflow-library` 或 `@monster_harryc/dsh-workflow-library`，请先禁用旧包，勿同时启用。新包继续使用原有工作流存储，不删除已有数据；包名变更不是 npm 原包的自动升级。
